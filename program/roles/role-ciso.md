# Chief Information Security Officer

Owns every document in this repository unless another role is named on it.

## Responsibilities

- Maintain the standards under `program/standards/` and keep their framework
  mappings current.
- Own the risk register and present it to the security committee quarterly.
- Set the capability roadmap and defend the budget that reaches it.
- Approve exceptions of up to six months; escalate longer ones to the CTO.
- Act as incident commander for `critical` incidents.

## Authority

- Accepts risks rated `medium` and below.
- Can stop a release that would breach a `mandatory` framework requirement.
