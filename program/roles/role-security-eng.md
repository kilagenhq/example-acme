# Security Engineer

Owns the controls that sit under the applications rather than inside them.

## Responsibilities

- Operate cloud security posture management and drive the findings to zero.
- Own the endpoint agent fleet and its coverage figures.
- Own key management and the encryption standards that depend on it.
- Maintain the hardening baselines for the platform accounts.

## Authority

- Approves changes to the production network boundary.
- Can quarantine an endpoint or revoke a cloud credential without prior notice.
